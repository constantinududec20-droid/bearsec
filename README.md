# BearSec

Site static pentru BearSec, un serviciu de monitorizare securitate / SOC pentru firme.

## Fisiere principale

- `bearsoc-index.html` - pagina principala a site-ului.
- `_mock.png` - imagine/mockup folosit in pagina.
- `_paw.png` - asset vizual/logo.
- `BearSec-Security-Basics-Checklist.md` - material checklist.
- `BearSec-Security-Basics-Offer.md` - material oferta.

## Cum continui pe alt PC

1. Copiaza tot folderul proiectului pe PC-ul personal prin OneDrive, ZIP sau GitHub.
2. Deschide folderul in VS Code.
3. Deschide `bearsoc-index.html` in browser sau cu Live Server.
4. In Codex, spune ca vrei sa continuam proiectul BearSec si mentioneaza acest README.

## Context rapid pentru Codex

Proiectul este un site BearSec in romana/engleza, cu branding dark, accent portocaliu, CTA pentru evaluare, sectiuni despre monitorizare de securitate, pricing si materiale de tip checklist/oferta.
